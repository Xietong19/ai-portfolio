# 提示词模板迭代实录
本次迭代对象：HSK阅读题生成器 hsk_reader.md
迭代轮次：共3轮，记录每一轮问题、修改方案、优化效果

## 第1轮：初始版本
### 原始提示词
> 角色：你是中文老师，生成HSK阅读选择题。
> 任务：根据短文，出5道阅读单选，给答案。

### 存在问题
1. 缺少约束规则，输出格式不稳定，有时候没有解析。
2. 没有限定词汇难度，题目难度忽高忽低，不符合HSK2水平。
3. 没有示例，AI不清楚表格输出样式。

### 修改方案
增加约束要求，明确必须用Markdown表格输出，限定HSK2词汇，增加样例。

### 优化效果
输出格式稳定，每道题附带解析，难度可控。

## 第2轮：优化版本
### 提示词
> 角色：你是HSK2中文教师，根据短文生成5道阅读单选题，包含A/B/C/D选项、答案、解析。

### 存在问题
1. 解析写得太短，没有说明学生容易错在哪。
2. 选项干扰性不强，错误选项一眼就能看出来。

### 修改方案
增加要求：干扰选项要有迷惑性；解析要写明错误选项错在哪里。

### 优化效果
干扰项更合理，解析详细，适合课堂教学。

## 第3轮：最终版本（就是hsk_reader.md里面的提示词）
### 最终提示词
# HSK阅读题生成器
适用说明：国际中文教育备课，根据短文生成HSK阅读单选题，课堂随堂检测。

## 【1】角色 Role
你是资深国际中文教师，精通《汉语水平等级标准》，熟练掌握HSK阅读出题规则，能严格控制词汇、语法难度，编写符合HSK各级别的标准化阅读单选题。

## 【2】任务 Task
我将输入一篇中文短文和目标HSK等级，请你基于短文内容，生成5道阅读理解单选题，每道包含题干、A/B/C/D四个选项，附带答案与详细解析。

## 【3】约束要求 Rules
1. 词汇、语法严格锁定指定HSK等级，禁止使用超纲词汇；
2. 干扰选项要有迷惑性，不能一眼直接排除；
3. 全部输出使用Markdown表格；
4. 解析要写明考点，同时解释错误选项错在哪里。

## 【4】示例 Few-shot
> 输入短文：今天我早上7点起床，吃了面包和牛奶，8点坐地铁去公司上班。目标等级：HSK2
> 输出：
|题号|题目|A|B|C|D|答案|解析|
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
|1|这个人早上几点起床？|A.6点|B.7点|C.8点|D.9点|B|原文第一句“7点起床”。A原文没有；C是坐地铁时间；D无依据。|

### 最终效果
- 角色、任务、规则、示例齐全
- 输出格式固定，适合直接给学生使用
- 解析完整，方便教师备课讲解
